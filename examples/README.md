# Examples

Sample programs for `emu8086-modern`. The folder will be populated milestone-by-milestone:

- M1 — minimal "registers and `mov`" examples used by the conformance tests.
- M2 — a port of the 12 sample programs shipped with legacy emu8086 v4.08, where licensing permits, plus public-domain alternatives.
- M3 — programs the IDE's "Examples gallery" links to.
- M4 — device-specific demos (traffic light, 7-seg, LED matrix).
- M7 — the 10 in-app tutorial programs.

Files added here should be teachable: short, well-commented, and exercise one concept at a time.
