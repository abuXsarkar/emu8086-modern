- **Tauri 2 desktop shell**. New `packages/desktop` crate wraps the
  web IDE in a native window for Linux, macOS, and Windows. The
  frontend stays the same React + Vite + Monaco bundle; the Tauri
  layer only owns window chrome and the platform webview. Dev loop
  hooks into the existing Vite HMR (`pnpm desktop:dev`); release
  bundles come from `pnpm desktop:bundle` (DEB + AppImage on Linux,
  DMG + .app on macOS, MSI + NSIS on Windows). Placeholder icons
  generated by `tools/gen-desktop-icons.py` keep the bundler happy
  until a designed icon set lands; the script's a stdlib-only
  Python file so any contributor can re-run it. CI's Rust matrix
  now installs the Tauri Linux deps (webkit2gtk, libdbus, etc.) so
  the desktop crate compiles on every push.
