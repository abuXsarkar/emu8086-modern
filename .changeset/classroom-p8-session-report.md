- **Classroom mode P8: session report + CSV export**. Two new
  buttons in the teacher footer: "🖨 Print summary" opens a fresh
  tab with a print-styled A4 attendance/activity sheet keyed by
  course metadata; "⤓ Export CSV" downloads the same data as a
  spreadsheet-friendly UTF-8 CSV (with BOM for Excel). Both are
  fully client-side and read straight from the live store, so a
  teacher can print mid-session or at the end without losing
  state. Filename includes the course code, date, and room id so
  artifacts drop into existing grading folders without renaming.
